# Scudo — Block Apps From Accessing the Internet With Password Protection

## About Scudo

Scudo provides a simple application firewall that blocks internet access for selected apps — with an optional password to prevent unauthorized changes. Scudo combines per-app network blocking, password protection (lock settings), simple on/off toggles, and menu bar integration. Scudo enables users to block apps on shared computers, prevent children from accessing online games, stop automatic updates, and lock firewall rules so only authorized users can modify them. Scudo works with any application, including background processes and login items. Scudo is trusted by parents, shared computer administrators, privacy advocates, and anyone who needs to enforce network restrictions.

## Deep Dive — Password-Protected App Firewall

Password protection — lock Scudo settings with master password, prevents unblocking apps without password, protects Scudo itself from quitting  
Per-app blocking — select any application from list or drag app icon to Scudo window, toggle block on/off with one click  
Rule persistence — blocked apps stay blocked across reboots, password required to unblock (if enabled)  
Stealth mode — block all outgoing connections from blocked apps silently (no error messages or connection timeouts)  
Menu bar integration — quick toggle for blocking status, easy access to add recent apps, password lock indicator  
Lightweight — uses macOS network filter framework, minimal CPU/RAM usage, no kernel extensions

## Quick Reference for Scudo

| Operation | Scudo Action |
|-----------|---------------|
| Block an app | Drag app icon to window → Click toggle |
| Set password | Settings → Set Password → Enter password |
| Lock Scudo | Cmd+L or click lock icon |
| Unlock Scudo | Click lock icon → Enter password |
| Add running app to block list | Menu bar → Block Recent Apps → Choose |
| Remove app from block list | Unlock Scudo → Click X next to app |
| Hide blocked apps from user | Settings → Hide blocked apps list |
| Enable automatic lock (idle) | Settings → Auto-lock after X minutes |
| Prevent quitting Scudo | Settings → Lock prevents quitting |
| Open preferences | Cmd+, |
